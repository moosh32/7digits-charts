# 7-DIGITS Charts

פלטפורמת גרפים מקצועית למניות ארה״ב — ממשק עברי מלא (RTL).

## מה יש כאן

- **חיפוש** על פני 13,263 מניות ותעודות סל אמריקאיות (מאגרי Nasdaq Trader הרשמיים)
- **מסגרות זמן**: דקה / 5 / 15 / 30 דקות / שעה / יומי / שבועי / חודשי
- **נתונים**: יומי–חודשי מ־Nasdaq הרשמי; אינטרדיי מ־Yahoo Finance (+גיבוי Twelve Data עם מפתח)
- **70+ אינדיקטורים** מובנים, כלי ציור, שמירת מצב הגרף
- **Pine Script** — הרצת אינדיקטורים ואסטרטגיות של TradingView (v5, ו־v6 נסיוני) ישירות על הגרף
- **רשימת מעקב** בעברית עם מחיר ושינוי יומי

## הרצה מקומית

```bash
npm install
npm run build
npm start   # http://localhost:3000
```

משתנה סביבה אופציונלי: `TWELVEDATA_KEY` (גיבוי נתונים).
